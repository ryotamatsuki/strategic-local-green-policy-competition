# Reviewer C — 経済メカニズム・厚生・制度

## C01（MAJOR） 自地域補助の調整後に何が反転するか

§4.1 の命題直後は負と正の意味を言い換えるだけ。§4.2 の θ=.9 の CS・PS・目標の数値は、自己補助を固定した直接交差微分である。確認すると θ=.5 **でも**直接効果は正（+0.00023684）。その一方で、最適反応の導関数は負（−0.00455222）。直接項の分解を反転の説明に使うのは危うい。

記号を自己政府目的 W の添字 `s=s_A, h=h_A, b=s_B` とすると、自己補助 FOC を消去して得る式は次。

```text
dh_A^BR / ds_B = −(W_hb − W_hs W_sb / W_ss) / (W_hh − W_hs² / W_ss).
```

分母は負。括弧内の成分を同じ Hessian で正規化した傾きへの寄与は次のとおり。成分ごとに別々の最適化をした比較ではない。

| θ | 消費者余剰 | 生産者余剰 | 目標 | 計 |
| ---: | ---: | ---: | ---: | ---: |
| .5 | −.001903 | −.035902 | +.033252 | −.004552 |
| .9 | +.003335 | −.075657 | +.079434 | +.007113 |

基準では強い競争で生産者余剰による負の寄与も増す。目標の正の寄与はそれ以上に増え、消費者余剰も正に変わる。直接目標効果は `−d E_h E_b` で、基準の高競争では、相手補助による自地域産出と排出の低下が、自己インフラを追加する際の目標損失の限界負担を軽くする。閾値の位置は、自己補助を調整した後の効果から読む。この二点分解と満たす範囲を命題直後に置く修正は、既存命題の説明なので Stage 10B/13 で可能。

## C02（MAJOR） 目標強度の感度表で政策の実現可能性が見えない

§6.3 は三つの d を内点診断として報告している。厳密な根数を再現したが、θ=.9 で `d=1.5` の対称内点 FOC 候補には相手の生産停止を伴う有利な政策逸脱があり、`d=3` では対称 FOC の `h_A≈−.3256` が不可能。表の注だけでは、読者がこの符号を各 d の実現する政府均衡に帰属させかねない。さらに §6.3 の「低い競争で他効果を相殺できるほど強い」という記述は負→正の方向と整合しない。高競争で相殺するが、低競争では相殺し切らない。

**独立の診断。** 排出が政策にアフィンなので、自地域 Hessian の目標成分はランク1。交差微分ベクトルと合わせた IFT の分子では d² が相殺される。基準の残りの原始パラメータでは、θで割った分子の d 係数は正。ゼロにする `d*(θ)` は厳密な有理式の根数検査で減少し、`d*(0)≈2.54707, d*(.5)≈2.31736, d*(.9)≈1.80619, d*(1)≈1.62838`。従って正の θ で、曲率と内点条件を課した上で、反応の符号は `d−d*(θ)`。θ=0 の値は極限で、反応そのものはゼロ。三点表を超える研究候補ではあるが、同帯域全域の均衡可能性を証明する結果として採用しない。表の名を「内点 FOC 分子の符号」にし、実現可能性を注記する修正は文章で可能。もし閾値面を新しい定理として採用するなら Stage 6 の貢献判定を経て、Stage 4/4A と 7.5A で証明・範囲を確定する。

## C03（MINOR） 協調と排出を、実行可能なベンチマークとして読む

§5 の選択集合は `(s_A,h_A,s_B,h_B)≥0` で、企業行動は誘導段階に残る。本文の計算はそのうち対称・複占枝。θ=.9 で総厚生 `2.18695→3.72031`、一地域の産出 `1.1842→2.3970`、排出 `.90746→1.63404` を原始式から照合。地域当たり CS の持分 `1.3322→5.4585`、PS `.8064→3.1645` の増加が、インフラ費用 `.2216→4.0928` と目標損失 `.8235→2.6701` の増加を上回る。協調比較が大域的・選択非依存だとは読めない。厚生向上は一つの実行可能な政策比較であり、どの大域協調解でも排出が増えること、地域内で補償なしに個々が賛成すること、または世界の気候厚生が改善することは導けない。§5 の「second-best」を「feasible coordinated active-duopoly benchmark」に揃える。差の存在には、より広い協調問題の最適化や排出順序の一般化は不要。

## C04（MINOR） 制度と反証できる予測

- METI の GX 戦略地域では電力等の共通インフラと企業向け投資支援が併存する。OECD は日本の自治体の約6割が2050年ネットゼロを表明したと報告。これらは政策の併存と地域目標の傍証で、自治体が相手の補助率に対して同時かつ独立にインフラを選ぶことは確認できない。自治体間の相互作用・炭素予算の権限・時間軸・自地域負担を政策処方に読み込まない。 [METI GX](https://www.meti.go.jp/policy/energy_environment/global_warming/gx_strategy_area.html) · [投資促進事業](https://www.meti.go.jp/policy/energy_environment/global_warming/gx_strategy_area/subsidy/subsidy.html) · [OECD Japan 2025](https://doi.org/10.1787/583cab4c-en)
- 反証可能なモデル含意は三つ。相手政策の片方を固定した正規化外生ショックに対する閾値、固定された相手指数に沿うショックへの不変性、二つの起点から測った同じ自己反応の比例関係（§4.2、§7）。二政策が内生的に一緒に動くデータだけでは偏微分を観測しない。代替性を直接表す指標、同じ競争市場への露出、政策ショックの独立変動が必要。高い目標重み d は観測した排出量の意味ではなく、制度上の目標未達の限界負担の規律。§7 と Discussion には桁 `.774` を自治体データに当てはめない旨と、比率を検証する際の単位を足す。この射程の診断論文に、協定実装やデータ分析を無条件の要件とはしない。
