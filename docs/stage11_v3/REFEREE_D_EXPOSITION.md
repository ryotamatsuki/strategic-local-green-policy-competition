## 改稿指示

- **D02（EDITORIAL、Stage 10B/13）**。主張を Abstract→Intro→命題→図→Discussion の各位置で一段発展させる。序論は `s_B` の偏微分で固定する変数と再最適化する変数を自然文一つで定義する。Discussion は同じ結論の反復を削り、過度に自己弁護的な §8 の採否評を実際の先行定理との差へ置き換える。二制度の働きと範囲を理解した読者が、新しい反証条件を一つ述べられることを再試験する。
