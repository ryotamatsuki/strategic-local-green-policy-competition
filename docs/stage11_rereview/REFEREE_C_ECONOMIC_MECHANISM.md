§4.1、式 (36) と p.10 Table 1 は完全に再現できる。分母 $K=W_{hh}-W_{hs}^2/W_{ss}$ と比率 $W_{hs}/W_{ss}$ は全政府目的で共通。成分の交差微分のみを分ける。CS は $\tfrac12 CS$、PS は投資実費控除後、目標は $-d(E-\bar E)^2/2$。インフラ費用は相手との二つの混合微分がゼロだが分母の曲率に効く。

高競争側では生産者の損失の負の寄与も増える。競合による国内産出・排出の変化を政策政府が評価するため、目標項の増分がそれを上回り、消費者項も正になる。仮に自地域補助を固定すると、評価対象が直接効果に変わり、この二点の符号の差は現れない。経済学上の違いを本文から読み取れる。大域一般化や定量的な政策効果の説明はこれらの数値からは出ない。

## C02 感度表の範囲は解消

§6.3、p.16 Table 4 は内点の根・符号と候補の可否を区別する。$\theta=.9,d=1.5$ の最良の独占枝逸脱 $(s_A,h_A)\approx(8.179207,5.353594)$ は厚生を $.295641$ 増やす。$d=2$ の指定SPNEは両政策が正であり逸脱との差は $.427751$。$d=3$ の内点候補は $h_A=-.325620$。さらに $\theta=1$ では境界そのもの $d=d^*(1)\simeq1.628378$ において対称複占候補から独占への逸脱が約 $.281410$ 有利。これはその候補を大域的な符号境界として読むことを排除する。別の政府均衡の不存在を意味しない。本文は明示的に同じ限定を置く。

## C03 協調、C04 反証条件

§5 と Table 3 は、指定した分権 SPNE と実行可能な対称複占の協調ベンチマークを比較。$\theta=.9$ で総モデル厚生 $2.187\to3.720$、各地域排出 $.907\to1.634$。資源費用・目標損失を含めても余剰増が両ケース間では大きい。大域協調最適や任意の選択にわたる福祉順位を導く証拠はない。C03 は解消。

§7 と §9 の等指数制約を裏付ける。各継続枝の $(q_A,q_B,u_A)$ と、A に関係する $x_A,g_A$ は A 自身の政策と $w_B=m+y_B$ で決まり、A の目的はこの組に関して不変。同じ初期条件・同じ $w_B$ の終点なら枝をまたいでも同一の大域最適反応**集合**。実際の選択値が等しいと主張するには同じ選択規則が必要。微分可能な枝では $\partial h_A/\partial s_B=(\mu/k_g)\partial h_A/\partial y_B$、$\partial h_A/\partial h_B=\nu\partial h_A/\partial y_B$。異なる初期指数から同じ $\Delta y_B$ を加えた比較を一般に同じ反応とは言えない。競争企業の立地、政策権限の対応、実物インフラの単位、相手政策の共通ショックの除外と対象市場へのエクスポージャーが必要。共同政策変化を観測するだけでは偏微分を識別しない。

C04 は PARTIALLY RESOLVED。§9 第3段落の *marginal welfare loss* は R03。単純な二次目標損失では $d$ は曲率、排出一単位への限界ペナルティは $d(E-\bar E)$。§7 の推定条件もこの区別に揃える。例えば制度的罰則が偏差の二次式に対応し得る場面で、その増加率を独立に把握するのであって、目標水準や実績の排出量から $d$ を読まない。潜在ウェイトの同定と、枝・選択を跨ぐ比較が実務上の制約。GX は制度的動機として出す射程に収まる。
